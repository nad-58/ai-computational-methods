# Release notes — v0.2.0

## AI Computational Methods

This release expands the repository from a method taxonomy into a runnable numerical learning resource covering symbolic AI, traditional machine learning, neural networks, transfer learning, and metaheuristics.

### Included

- Numerical examples for every major method family
- Inspectable CSV datasets
- Intermediate calculations, predictions, metrics, and data flows
- Unified numerical runner
- Tests for numerical examples
- Original diagrams and worked tutorial
- CI for standard examples
- Dedicated CI for the full numerical suite
- Dependency auditing and Dependabot
